# 人物头顶小窗（2026-11-16）

头顶卡片分开显示体感温度、emoji 心情/冷热预警、可展开的健康建议。展开建议不会替换心情；移动、温度更新和切换界面语言也不会将已展开的建议收起。新获取的建议默认收起，由用户决定是否展开。

体感值直接使用仪表盘相同的当前位置 UTCI 估算或区域参考体感，沿用人物移动时的更新节奏，不增加气象 API 调用。日照演示标明演示，旧天气标明待更新，无有效值时显示 --°C。

原健康建议请求同时返回完整建议和两句以内短版，DeepSeek 模型及思考参数不变。完整建议留在仪表盘；头顶显示短版、生成时间、非专业医疗建议标记，以及前往完整建议的链接。旧格式回答可按完整句子提取预览，不在句中截断。AI 连接失败时，仅展示明确标为基础提醒的现有规则建议。

建议仅保留在当前页面内存，不新增持久化。WebGL 场景和二维回退共用同一组件。小窗支持触摸、键盘展开及中英文界面，390px 窗口下没有横向溢出；展开内容可滚动，温度与心情仍共同显示。

验证：108 项测试通过，包括零度/缺失值、仪表盘与头顶体感取值一致、完整与短版分离、保留限水医嘱、一次请求返回两种文本。浏览器确认实际场景温度随跳转更新并与仪表盘一致、emoji 共存；用虚构建议验证了展开/收起、展开时温度和心情变化、新建议默认收起及手机边界。未为界面验证向 DeepSeek 额外发送个人资料。
