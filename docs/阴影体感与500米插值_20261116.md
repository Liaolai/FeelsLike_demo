# 阴影体感、断桥步行和500米插值更新

## 原因与行为更正

旧版顶部大数字是区域参考值，不随单棵树影变化；tjweather没有太阳辐射字段；手动选白天时可能沿用当前夜间零辐射。本版顶部显示有明确标记的当前位置UTCI估算，区域参考仍在来源行单独保留。身体周围五点遮蔽求交继续使用真实显示的树冠/建筑网格，人物位置报告间隔缩至250毫秒。

## 辐射与体感计算

当前时间：优先有效气象短波辐射。手动日照演示：优先所选小时的逐时辐射，不能把当前夜间0当作白天数据。缺失辐射时用Haurwitz晴空模型并明确标为模型估算，不能称为实测或当日真实辐射；它不包含实际云遮挡，因此有辐射预报时优先使用预报。夜间短波为0。

```text
若需晴空估算：GHI = 1098×sin(太阳高度角)×exp(-0.059/sin(太阳高度角))
散射近似 = 0.25×GHI
直射近似 = 0.75×GHI
人体所在点短波 = 散射 + 直射×(1-遮蔽比例)
吸收短波近似 = 0.7×0.25×人体所在点短波
Tmrt = ((Ta+273.15)^4 + 吸收短波/(0.97×5.670374419e-8))^(1/4)-273.15
局地UTCI = UTCI多项式(Ta,Tmrt,参考10米风速,RH)
阴影影响 = 当前UTCI - 同一天气下无遮挡UTCI
```

散射/直射比例、吸收率、人体投影比例与环境长波等于气温是近似假设；树冠按当前不透光几何判断，没有实测叶片透射率或人体核心体温。保留UTCI输入范围检查和0.5m/s最低风速处理。

页面同时展示日晒参考、当前位置结果、阴影影响、遮蔽比例、辐射值及来源。真实时间模式下可参与原有建议；手动模式是日照演示，继续使用当前温湿风，保留原有真实提醒不被演示改写。夜间/零直射时不制造阴影降温。

测试例：28°C、RH60%、风1m/s、太阳高度60°、晴空模型约888W/m²，无遮挡UTCI约34.74°C，全遮阴约30.43°C，差约-4.31°C。这是算法复现例，不是西湖现场测量。

公式来源：[pvlib Haurwitz实现](https://pvlib-python.readthedocs.io/en/stable/_modules/pvlib/clearsky.html)。UTCI多项式保留原模块的pythermalcomfort来源和MIT声明。

## 断桥不再依赖地形猜测高度

从实际渲染步道三角形建立空间索引，人物脚底查实际桥面高度。桥/堤路径加密，删除缺少路面支撑的连接；手动、自动和屏幕方向按钮都检查整段移动，缺路面就停下，不走进水里。桥梁高度不再退回湖底地形。断桥路线85个采样点支撑检查通过，桥面高度一致；断桥与苏堤三组连接仍通过。见verification/path-tree-repair.json。

## 500米温度网格

在120.142°E、30.248°N局部米制原点上生成500米等距网格。对有效原始源点去重，采用最近4点、距离平方反比权重IDW；源点位置精确保真，等值输入保持等值，温度/体感各按自身有效样本与凸包计算，凸包外不外推。单源点保留同值并标明来源，不制造温差。

500米是插值与展示间距，原预报分辨率没有因此变细。地图显示源点数量和500米插值说明；温度数字只在点击位置后出现，信息框用深绿底；取消常驻白底温度和地点底板，原始数值不改写。
