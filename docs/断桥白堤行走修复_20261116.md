# 断桥—白堤手动行走修复（2026-11-16）

本轮修正实际控制问题，沿用现有道路、碰撞与地形数据。

旧版在每次移动时将人物朝向重置为当前道路方向，因此手机先点转向、再点前进时，转向很容易在真正到达路口前丢失。方向评分还会拒绝约直角的后续路段。旧的几何验收只检查道路支撑与碰撞，未覆盖这种连续手动选路行为。

现在保留用户转向意图，直到真正分岔口再使用；普通的道路中间节点和直角弯继续沿唯一后续道路行走，末端仍停下，松开移动键也仍立即停止。碰撞拒绝移动时，恢复位置和全部转向状态。断桥初始进入点改为模型中断桥主路上的安全节点，默认面向白堤西向；跳转与路线终点使用同一个点。

验证：

- 111 项单元与回归测试通过，新增直角弯、手机提前转向跨越中间节点、断桥朝向测试。
- 使用网站同一个 walkGraph 和实际路面/身体碰撞，模拟手机每次 4 米及键盘每帧前进：分别走完 864 米、862.96 米白堤，无阻塞。
- 断桥到平湖秋月、平湖秋月到断桥，各 932.67 米，逐帧接触检查通过。
- 白堤中轴连续检查无阻塞。
- 浏览器确认从新断桥落点向前移动，以及从平湖秋月走过旧版卡住的直角弯；位置持续更新，停止后 moving=false，walkBlock 为空，控制台无错误。

完整本轮结果：verification/baidi-runtime.json；复验命令：node scripts/check_baidi_runtime.mjs。
